# SerpApi Go Jobs Finder

A simple example project in Go using the SerpApi Google Jobs API.

## Goal
Help Go developers programmatically search for remote developer jobs using SerpApi.

## How to Run

1. Get a free API key at serpapi.com
2. Install dependencies:
    ```bash
    go get github.com/serpapi/google-search-results-golang
